## homeiot

A local dashboard for the IoT devices on my network — Philips Hue lights,
plugs, sensors and switches, with rooms, zones, scenes and my own collections.
Standard-library Python plus a no-build frontend.

    python3 -m homeiot --demo    # simulated devices
    python3 -m homeiot           # find and pair a real bridge

See [homeiot/README.md](homeiot/README.md).
